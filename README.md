# Week 2: Intro to AI

This project is dedicated to studying development with AI and autocomplete. The exercises within are designed to inform the student (ME!) about the methods, utilities, and dangers, inherent in using AI to write code that the programmer does not understand.

This lesson contains a calculator designed to evaluate the value of x using a brute-force search algorithm, as well as  perform basic arithmetic. The code contains a visualizer for that search operation, and features a study of python's AST library for the evaluation of expressions.

I learned a lot about how to manage sort-of wrangle an AI to stick to a strict scope, and maintain the specifications outlined by the assignment. I also learned a great deal about how to actually practically employ a library to do something helpful!
